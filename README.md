## Selected work

### [Traffic & Air Pollution Visualization](https://kmmubin.me/traffic-air-pollution-visualization/)

An interactive D3.js data story examining traffic and air-quality patterns across U.S. states using monthly data from 2015–2025. It combines a choropleth map, timeline, scatter analysis, coordinated filters, and explanatory storytelling.

**Stack:** JavaScript, D3.js, HTML, CSS, data visualization  
[Live visualization](https://kmmubin.me/traffic-air-pollution-visualization/) · [Source code](https://github.com/itzmubzy/traffic-air-pollution-visualization)

### [ChasiConnect](https://kmmubin.me/cashiconnect/)

An agricultural collaboration and investment prototype connecting farmers, landowners, and investors through land leasing, project funding, field-progress tracking, harvest reporting, and transparent profit distribution.

**Stack:** PHP, MySQL, JavaScript, HTML, CSS  
[Static showcase](https://kmmubin.me/cashiconnect/) · [Source code](https://github.com/itzmubzy/cashiconnect)

### [ChildConnect](https://github.com/itzmubzy/ChildConnect)

An all-in-one system for children's care, health, education, and finances, with workflows supporting transparent sponsorship, donations, and adoption processes.

**Stack:** C#, .NET, relational data modeling
